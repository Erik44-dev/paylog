Вход в панель

Панель пишет статьи прямо в репозиторий GitHub. Токен хранится только на этом устройстве.

Нужен токен с правом Contents: read & write на этот репозиторий. Он не уходит никуда, кроме api.github.com.

Создать токен: github.com/settings/personal-access-tokens/new
Repository access → только этот репозиторий · Permissions → Contents: Read and write.

Как это работает

Панель не хранит статьи у себя — она коммитит файл data/posts.json в твой репозиторий на GitHub. GitHub Pages пересобирает сайт за 30–90 секунд.

  • Новая статья — заполни поля и нажми «Сохранить». Сайт обновится сам.
  • Черновик — сними галочку «Опубликовано», статью никто не увидит, но текст сохранится.
  • Главная — одна статья с галочкой «Главная статья» показывается блоком сверху.
  • Реф-ссылка — вставь партнёрскую ссылку в поле, и на странице появится кнопка перехода.
  • Видео — вставь ссылку YouTube; плеер подгружается только по клику (сайт остаётся быстрым).

Безопасность

Адрес панели нигде на сайте не указан и закрыт от поисковиков. Войти можно только с токеном GitHub — он лежит в памяти этого браузера и стирается кнопкой «Выйти». Никогда не вставляй токен на чужом устройстве.
